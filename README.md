# Simple Interest Calculator

This repository contains a Bash script that calculates simple interest using the principal amount, annual interest rate, and time period.

## Description
The Simple Interest Calculator accepts three inputs from the user and calculates the interest earned or payable.

## Inputs
- Principal (P): Initial amount of money
- Rate (R): Annual rate of interest in percentage
- Time (T): Time period in years

## Formula
Simple Interest = (P × R × T) / 100

## How to Run
1. Clone this repository.
2. Open a terminal in the repository directory.
3. Run `bash simple-interest.sh`.
4. Enter the principal, rate, and time when prompted.

## Example
Principal: 1000
Rate: 5
Time: 2

Simple Interest: 100
